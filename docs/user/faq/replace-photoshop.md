---
title: Can Oracle Edit replace Photoshop?
description: Not yet. Oracle Edit is in early alpha and is not ready for daily professional work, but it follows Photoshop's menus and shortcuts.
order: 30
verified: 0.9.0
---

Not yet. Oracle Edit is in early alpha. Much of Photoshop's feature surface exists in some form, but the project says plainly that it is not yet a Photoshop replacement for daily professional work.

The biggest gaps the project lists are AI and generative features, tools Photoshop has that Oracle Edit does not yet, depth in typography and professional workflows, and plug-in compatibility. Every Photoshop menu item is connected to a command, but that only shows the menu is wired up. Having a tool or command is not the same as matching Photoshop's behaviour.

What Oracle Edit does well already: layers, masks, adjustment layers, layer styles, type, vector shapes, brushes and live-preview filters, in a menu and shortcut layout that follows Photoshop. See [Oracle Edit](../index.md) for an overview, and the [project roadmap](https://github.com/Marvingxx/oracle-edit/blob/main/ROADMAP.md) for what comes next.
