title: Is Oracle Edit free?
description: Oracle Edit is free and open source under the MIT or Apache 2.0 license, and works offline.
order: 10
verified: 0.8.2
---

Yes. Oracle Edit is one of the Crafting Apps, which the project describes as free, open-source creative tools. The code is licensed under MIT or Apache 2.0, your choice, and is on [GitHub](https://github.com/Marvingxx/oracle-edit).

Oracle Edit works offline. Its smart selection tools run on your computer, with no cloud and no account.

The ArtCraft logos in the repository are not open source.

See [Install Oracle Edit](../getting-started/install.md) to download it.
