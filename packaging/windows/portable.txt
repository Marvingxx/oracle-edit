Oracle Edit portable mode

While this file sits next to oracle-edit.exe, Oracle Edit keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the Oracle EditData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Oracle Edit with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\OracleEdit for settings
and %LOCALAPPDATA%\OracleEdit\Recovery for crash-recovery autosaves. If Oracle EditData can't be
written (for example on a read-only drive), Oracle Edit says so and uses those folders instead.
